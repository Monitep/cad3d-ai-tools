Novità / What’s new · 0.9.14

Italiano

Installazione più sicura: prima di aggiornare i file, Vetra controlla che programmi e librerie della cartella siano liberi. Se una finestra, un lavoro o un collegamento MCP/CLI li usa ancora, l’installer attende brevemente e poi invita a chiuderli e riprovare. Nessuna chiusura forzata dei lavori. Migliorato il rilascio del motore CUDA alla chiusura dell’app, anche durante gli aggiornamenti.

English

Safer installation: before updating files, Vetra checks that the folder’s programs and libraries are free. If a window, job or MCP/CLI connection still uses them, setup waits briefly and then asks you to close them and retry. Running jobs are never forcibly closed. Improved CUDA engine release when the app exits, including during updates.

Local image restoration and upscaling. Requires Windows 10 22H2 64-bit or Windows 11 64-bit. Close Vetra and run the installer: it detects the previous installation and keeps models and settings. If an old ZIP copy cannot be located reliably, select its folder once. Models download on demand.
