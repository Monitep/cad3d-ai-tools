Italiano

Batch più semplice: seleziona le miniature o usa Seleziona tutte, regola una foto e premi Applica impostazioni alle selezionate. Cliccando la foto in elaborazione puoi seguire i riquadri che si aggiornano. Le modifiche alle immagini ancora in coda vengono applicate alla generazione; i parametri della foto già in elaborazione restano bloccati. Modelli e impostazioni conservati.

English

Easier batch editing: select thumbnails or use Select all, adjust one photo, then choose Apply settings to selected. Click the photo being processed to follow its live tile updates. Changes to images still waiting in the queue are used for generation; settings for the photo already being processed are locked. Models and settings are preserved.

Local image restoration and upscaling. Requires Windows 10 22H2 64-bit or Windows 11 64-bit. Close Vetra and run the installer: it detects the previous installation and keeps models and settings. If an old ZIP copy cannot be located reliably, select its folder once. Models download on demand.
