Novità / What’s new · 0.9.15

Italiano

Zoom di dettaglio con pixel reali, senza sfocatura aggiunta durante l’ingrandimento. L’anteprima a riquadri viene rimossa appena il risultato completo è pronto; le regolazioni live non possono sostituirlo con una cache di dimensioni diverse. Aggiornamento nella cartella corretta dell’app e chiusura automatica delle istanze di Vetra in quella cartella, forzata se non rispondono. Modelli e impostazioni conservati.

English

Detail zoom displays actual pixels without added blur during magnification. The tile preview is removed as soon as the full result is ready; live adjustments cannot replace it with a differently sized cache. Updates target the app’s actual installation folder and automatically close Vetra instances in that folder, forcing unresponsive instances to exit. Models and settings are preserved.

Local image restoration and upscaling. Requires Windows 10 22H2 64-bit or Windows 11 64-bit. Run the installer: it detects the previous installation, automatically closes Vetra instances in the folder being updated, and keeps models and settings. Finish running jobs before installing. If an old ZIP copy cannot be located reliably, select its folder once. Models download on demand.
