Che cosa puoi sapere

Stato della versione, configurazione osservata e prossimi passi. Il risultato non dimostra lo sfruttamento della falla e non certifica l’intero sito.

Verifica sul tuo sito

1

Prepara il file diagnostico

Scaricalo e caricalo tramite il pannello del tuo hosting nella cartella PHP da controllare. È protetto da una chiave e scade dopo un’ora. Richiede PHP 5.4 o successivo.

Mantieni aperta questa scheda: contiene la chiave. Il file non esegue comandi e non modifica la configurazione.

2

Collega il file caricato

Usa direttamente l’indirizzo HTTPS finale, senza reindirizzamenti. Scegli una cartella con lo stesso runtime delle pagine del sito.

3

Conserva il risultato e rimuovi il file

Esporta il report prima di cancellare il file diagnostico dal server. Ripeti il controllo sui diversi pool, nodi o cartelle che usano configurazioni PHP diverse.

Hai già la versione PHP?

Leggila nel pannello hosting o nelle informazioni del sito. Il PHP da terminale può essere diverso da quello che serve le pagine web.

Un backport è una correzione applicata dal provider a una versione precedente. Il riferimento viene conservato come dichiarazione, senza considerarlo una conferma indipendente.

Due falle del runtime PHP

CVE-2026-109618

Una gestione non corretta dell’esaurimento della memoria può lasciare dati interni incoerenti, utilizzati durante la chiusura della richiesta.

CVE-2026-109619

Alcuni dati globali possono restare collegati alla memoria liberata da una richiesta ed essere utilizzati da una richiesta successiva.

Le condizioni dipendono anche dalla modalità di esecuzione, dalla configurazione e dall’applicazione. L’avviso PHP comprende FPM, mod_php, CGI, FrankenPHP e LiteSpeed.

Se il controllo non si collega

404: verifica percorso e file; può anche indicare una chiave non valida. 410: il file è scaduto; rigeneralo e ricaricalo. Errore di rete: controlla HTTPS, reindirizzamenti, CORS e le regole del provider. Se gli header X-Audit-* vengono rimossi dal proxy, il controllo non può autenticarsi.

Limiti della verifica

La lettura riguarda un solo runtime in un dato momento. Il file aggiunto potrebbe non usare lo stesso pool delle pagine applicative. Versioni dichiarate e backport richiedono riscontro con i pacchetti del provider. Un risultato corretto oggi non esclude compromissioni precedenti, altre vulnerabilità o nodi rimasti da aggiornare. Le opzioni INI lette nello script possono non coincidere con quelle applicate prima dell’avvio della richiesta.
