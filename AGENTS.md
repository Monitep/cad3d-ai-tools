# Instructions for AI collaborators

This repository contains several independent projects. For the CAD3D.Expert website
(`cad3d-preview/`), first read [.github/cad3d-site/AGENTS.md](.github/cad3d-site/AGENTS.md)
and [.github/cad3d-site/README.md](.github/cad3d-site/README.md).
Those instructions are scoped to CAD3D, not to the other applications in this repository.

For updates to the public website at `https://www.cad3d.expert/`, also read
[.github/cad3d-live/AGENTS.md](.github/cad3d-live/AGENTS.md) and
[the publication guide](.github/cad3d-live/README.md). The public site has newer
content than the preview source in this repository. Never deploy that entire
preview over the current public website. Use the reviewed selective release.

The root `index.html` belongs to the existing `/ai/` area. It is not the new CAD3D home.
