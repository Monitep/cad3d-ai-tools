# CAD3D.Expert project entry point

For work on the CAD3D website, read `AGENTS.md`, then
`.github/cad3d-site/AGENTS.md` and `.github/cad3d-site/README.md`.

The editable source is `.github/cad3d-site/`. `cad3d-preview/*.html` and
`cad3d-preview/en/*.html` are generated files. Change the source and rebuild them.
The CSS, JavaScript and media under `cad3d-preview/assets/` are edited directly.

Use the existing GitHub and Aruba workflow. Other projects in this repository have
their own scope. Do not substitute the repository root page for the CAD3D home.
